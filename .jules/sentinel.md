## 2026-06-22 - [GeoIP HTTPS Hardening]
**Vulnerability:** Geographic location data was transmitted over insecure HTTP (ip-api.com), and the application globally allowed cleartext traffic.
**Learning:** Hardening production network security requires careful coordination with E2E tests that may rely on local HTTP mock servers. Using Android source sets (debug vs main) allows for a "Secure by Default" production posture without breaking developer workflows. Additionally, manifest merger conflicts in Hilt-enabled projects can lead to startup failures if debug overrides do not explicitly include all attributes subject to `tools:replace` in the main manifest.
**Prevention:** Always use HTTPS for external API calls. Use `android:usesCleartextTraffic="false"` and a restrictive `network_security_config.xml` in the main source set. Use the `debug` source set to provide necessary exceptions for testing, ensuring all replaced manifest attributes are explicitly defined to maintain Application initialization integrity.
