## 2025-01-22 - Information Exposure via UI Exception Messages
**Vulnerability:** CWE-209: Information Exposure Through an Error Message. The `getUserMessage()` method of the `VpnError` data class originally returned `details ?: message` to the user interface. Because `details` was populated with raw stack trace strings (`e.stackTraceToString()`), any low-level exception or connection failure would leak full Kotlin/JVM stack traces (including code paths, class names, line numbers, and internal libraries) directly onto the settings screen.
**Learning:** This occurred because developers used a unified `VpnError` object for both detailed logging and user display. When constructing user-facing error strings, they prioritized showing "all details" over interface sanitization.
**Prevention:** Separate debug-level log information from user-facing UI messages. Ensure `getUserMessage()` or any equivalent UI-bound methods only ever reference high-level sanitized strings, while preserving raw exception stack traces purely for internal logger frameworks or safe crash-reporting tools.
