## 2023-11-20 - Enforcing Global HTTPS & Restricting Debug Overrides in Android Manifests
**Vulnerability:** Unencrypted HTTP cleartext leaks through `ip-api.com` in production (CWE-319) and potential exposure of sensitive VPN credentials/configurations through default Android auto-backups.
**Learning:** Enabling unencrypted HTTP globally or via broad domain exemptions in `network_security_config.xml` compromises traffic privacy. Migrating to HTTPS-capable GeoIP services (like `freeipapi.com`) is essential, but requires removing the leading slash from the relative Retrofit endpoints (e.g., `json` instead of `/json`) to resolve cleanly against base URLs ending in `/api/`.
**Prevention:** Hardened production by setting `usesCleartextTraffic="false"` and `allowBackup="false"` in the main manifest. Safely delegated local unencrypted testing to `src/debug/AndroidManifest.xml` using targeted `tools:replace="android:allowBackup,android:usesCleartextTraffic"` to avoid Hilt-related merger conflicts.
