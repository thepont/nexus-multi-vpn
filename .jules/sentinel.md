## 2026-07-06 - [HIGH] Fix unencrypted GeoIP lookup
**Vulnerability:** Cleartext Transmission of Sensitive Information (CWE-319). Geographic location and IP data were being sent over insecure HTTP via ip-api.com.
**Learning:** Transitioning to HTTPS-only communication (harden Network Security Config) is essential but can break E2E tests (Maestro) and local development if not properly scoped with debug manifest overrides. Manifest merger conflicts occur when `tools:replace` is used in both main and debug manifests without matching attributes (android:name, android:theme, etc.). To override security hardening (e.g., cleartextTrafficPermitted) in debug builds via app/src/debug/AndroidManifest.xml, use `tools:replace` for ALL attributes subject to replacement in the main manifest to avoid merger failures. Redundant `android:name` in debug manifest can cause instability in some CI environments, but complete `tools:replace` is often required for build success.
**Prevention:** Always use GeoIP providers that support free HTTPS (like freeipapi.com). Maintain separate Network Security Configs for debug and release. Use exhaustive `tools:replace` lists in debug manifest overrides to ensure build consistency across environments.
