## 2026-07-06 - [HIGH] Fix unencrypted GeoIP lookup
**Vulnerability:** Cleartext Transmission of Sensitive Information (CWE-319). Geographic location and IP data were being sent over insecure HTTP via ip-api.com.
**Learning:** Transitioning to HTTPS-only communication (harden Network Security Config) is essential but can break E2E tests (Maestro) and local development if not properly scoped with debug manifest overrides. Manifest merger conflicts occur when `tools:replace` is used in both main and debug manifests without matching attributes (android:name, android:theme, etc.).
**Prevention:** Always use GeoIP providers that support free HTTPS (like freeipapi.com). Maintain separate Network Security Configs for debug and release. Use explicit attribute matching in debug manifest overrides to ensure stable Hilt/Application initialization.
